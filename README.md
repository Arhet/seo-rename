# SEO Rename

SEO Rename is a lightweight Windows utility that renames files using SEO-friendly transliteration.

## Features

- Russian → Latin transliteration
- Lowercase filenames
- Spaces → hyphens
- Removes invalid characters
- Preserves extensions
- Handles duplicate filenames
- Windows Explorer context menu
- Portable single executable
